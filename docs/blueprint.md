# **App Name**: Tabula Nova

## Core Features:

- Background Customization: Allow users to customize the background with images or solid colors.
- Link Folder Management: Enable users to organize pinned links into named folders (e.g., Favs, Stream, News).
- Browser Extension: Set the new tab page as a firefox extension.
- AI-Powered Search: Integrate a search bar powered by ChatGPT, to perform various operations and Q&A.
- Weather Display: Display current weather data for a user-configured location.

## Style Guidelines:

- Primary color: A muted blue (#64B5F6) reminiscent of a clear sky, promoting a calm and focused atmosphere.
- Background color: A light gray (#F0F4F7) to provide a neutral backdrop that allows the pinned links and weather information to stand out.
- Accent color: A warm orange (#FFAB40) for interactive elements and highlights, drawing attention without overwhelming the user.
- Clean and readable typography to ensure links and information are easily legible.
- Simple and intuitive icons to represent folders and common actions.
- Grid-based layout to provide structure and allow links to be presented neatly.
